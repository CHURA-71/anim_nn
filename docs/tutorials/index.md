# チュートリアル

anim_nnモジュールの学習ガイドです。

## 学習パス

### 初心者向け
1. **基本概念** - ManimCEとanim_nnの概要
2. **ニューラルネットワーク** - 基本的なネットワーク構造の可視化
3. **アニメーション基礎** - Create、FadeIn、Transformの使い方

### 中級者向け
1. **トランスフォーマー** - トークン化と埋め込みの可視化
2. **畳み込みネットワーク** - フィルターと特徴マップの可視化
3. **カスタムアニメーション** - 独自のアニメーション作成

### 上級者向け
1. **複合可視化** - 複数の概念を組み合わせた可視化
2. **パフォーマンス最適化** - 大きなデータセットの処理
3. **教育コンテンツ作成** - 完全な教育用アニメーションの作成

## 前提条件

- Python 3.8以上
- ManimCEの基本知識
- ディープラーニングの基礎概念

## 環境セットアップ

```bash
# 依存関係のインストール
pip install -r docs/requirements.txt

# ManimCEの設定確認
manim --version
```

## 学習のコツ

1. **段階的に学習** - 簡単な例から始めて、徐々に複雑にしていく
2. **実際にコードを書く** - 例をコピーするだけでなく、自分で変更してみる
3. **エラーを恐れない** - エラーは学習の一部、デバッグスキルも向上する
4. **コミュニティを活用** - 質問や共有を積極的に行う

## トラブルシューティング

### よくある問題

1. **ManimCEのインストールエラー**
   ```bash
   pip install manim
   ```

2. **フォントエラー**
   - 日本語フォントがインストールされているか確認
   - システムフォントの設定を確認

3. **メモリ不足**
   - 大きなネットワークの場合は、ニューロン数を減らす
   - レンダリング品質を下げる（-lフラグ）
